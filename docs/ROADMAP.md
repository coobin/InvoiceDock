# 路线图

## v0.1（当前）

- IMAP 附件和直接下载链接归集
- 手动上传、文件/业务去重
- 税务 2.02 识别查验优先
- 本地 OCR/文本层 + OpenAI 兼容 LLM 双源一致性
- 人工复核、审计、Excel、A4 1/2/4 联
- 本地账号、OIDC、Docker 单机部署

## v0.2

- 税务 2.01：人工纠正查验要素后再次请求官方查验
- 独立任务队列、失败重试、任务进度与取消
- 可选 PaddleOCR / RapidOCR 适配器和样本基准测试
- OFD 浏览器预览与打印转换
- 邮箱规则、发件人白名单、日期回溯和单邮件重新消费

## v0.3

- 受控浏览器链接恢复 worker（供应商页面、登录检测、验证码转人工）
- 报销集、附件/行程单配对、批次导出
- PostgreSQL、多租户数据隔离、对象存储
- Webhook/API token 与 ERP/财务系统推送
- 备份、保留期限、归档完整性校验和不可变存储策略

路线图不是交付承诺。优先级由真实样本、接口沙箱和社区 Issue 决定。
